# BlinkIT Grocery Sales Analysis – Power BI

## Project Overview

This project analyzes BlinkIT grocery sales data using Microsoft Power BI to understand sales performance across products, outlet characteristics, outlet locations, and customer ratings.

The project includes an interactive Power BI dashboard with KPI cards, data visualizations, DAX measures, and interactive filters.

## Tools & Technologies

- Microsoft Power BI
- DAX
- Microsoft Excel

## Key KPIs

- Total Sales
- Average Sales
- Number of Items
- Average Rating

## Analysis Performed

- Sales by Item Type
- Sales by Fat Content
- Sales by Outlet Size
- Sales by Outlet Location
- Sales by Outlet Establishment Year
- Performance by Outlet Type
- Customer Rating Analysis

## Dashboard Features

- KPI cards for key performance indicators
- Interactive visualizations
- Slicers for filtering the analysis
- Product and outlet performance comparison
- Sales trend analysis
